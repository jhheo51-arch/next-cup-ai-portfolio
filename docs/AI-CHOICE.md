# AI를 둔 이유와 비교 결과

## AI가 꼭 필요한 서비스인가요?

아닙니다. 등록 메뉴 5종의 필터링에는 AI가 필요하지 않습니다.
AI를 둔 곳은 기억을 자유롭게 적는 입력 단계입니다. 특징 이름을 직접 찾기 어려울 때 조건의 초안을 채우는 역할입니다.
이미 조건을 아는 사람에게는 직접 선택이 더 단순할 수 있어 두 경로를 유지했습니다.

## 무엇을 비교했나요?

기존 실제 Gemini 응답 3개를 화면에 다시 적용하고, AI 없이 빈 확인 화면에서 시작하는 경우와 비교했습니다.
두 방식 모두 동일한 목표 조건으로 수정하고 같은 후보가 나오는지 확인했습니다.
대상과 목표를 기존 결과를 본 뒤 선정한 사후 비교입니다. 독립적인 성능 평가나 사용자 실험이 아닙니다.

| 가상 사례 | 직접 선택 값 변경 | AI 응답 재생 후 값 변경 | 관찰 |
|---|---:|---:|---|
| R01 요거트와 갈린 질감, 초콜릿 제외 | 5 | 1 | AI가 선호 2개, 비선호 1개, 쌀 허용을 채움. 요거트 필수는 사람이 지정 |
| R02 쌀 풍미 필수 | 2 | 0 | AI가 쌀 선호와 필수를 채움. 두 경로 모두 추천 보류 |
| R03 바닐라에서 과일/갈린 질감으로 변경 | 6 | 6 | 기존 AI 조건을 지우는 작업이 생김. 변경 수 이점 없음 |

숫자는 체크/선택 값이 바뀐 횟수입니다. 클릭 횟수, 사용 시간, 정신적 부담이나 편의 점수가 아닙니다.
기억 입력, 전송 동의, AI 대기, 설명 읽기, 펼침과 제출은 계산에 포함하지 않았습니다. 따라서 합계 감소를 시간 절감률로 바꾸지 않습니다.
R03은 AI가 틀린 것이 아니라 시험자가 의도적으로 취향을 바꾼 사례입니다.
이번 비교의 외부 API 호출은 0회, 외부 참여자는 0명입니다.

## 그 결과 무엇을 결정했나요?

- AI가 모든 사람에게 더 낫다는 홍보 문구를 쓰지 않습니다.
- AI의 역할은 조건 초안 작성으로 제한하고 필수 조건 지정과 최종 확인은 사람에게 둡니다.
- 직접 선택을 숨기거나 AI 사용을 강제하지 않습니다.
- 추천 후보 일치만 검사하지 않고 추출 조건도 따로 검사합니다. 조건 오류가 최종 후보에서 드러나지 않을 수 있기 때문입니다.

## 어려운 문장 평가의 실제 상태

기존 16문장 기준을 유지하고 재시도했습니다. 기본 모델은 TIMEOUT/UPSTREAM, 시험용 2.5 모델은 MODEL 오류, 시험용 3.5 모델은 UPSTREAM/TIMEOUT으로 각각 2회 뒤 중단했습니다.
대체 모델은 평가 프로세스에만 설정했고 서비스 기본값은 바꾸지 않았습니다. 서로 다른 모델을 같은 성능 수치로 합산하지 않습니다.
별도 기본 모델 연결 점검에서는 HTTP 503과 UNAVAILABLE 응답을 직접 확인했습니다. 응답 내용은 요청량 증가를 알렸습니다. 전체 Gemini 서비스 장애로 일반화하지 않습니다.
[Google 오류 안내](https://ai.google.dev/gemini-api/docs/troubleshooting)도 503을 별도 다룹니다.

평가 답변을 받지 못했으므로 새로운 의미 정확도나 개선율은 여전히 없습니다. 기준을 바꾸거나 가상 정상 답변을 실제 응답으로 채우지 않았습니다.
개발 실패 8개와 분리 평가 8개가 아니라, 개발용 8개/분리용 8개를 준비한 뒤 연결 단계에서 멈춘 상태입니다.

## 연결 오류에서 고친 것

이전에는 503도 일반 UPSTREAM으로 묶여 키 오류나 네트워크 문제와 구분하기 어려웠습니다.
고정한 503 응답을 넣는 검사를 먼저 작성했을 때 실패했고, UNAVAILABLE/HTTP 503으로 분류하고 직접 선택을 안내하도록 고친 뒤 통과했습니다.
서버 응답 분류와 운영 기록이 바뀐 것이며, 제공자 장애를 복구하거나 모델 품질을 개선했다는 뜻은 아닙니다.

## 아직 필요한 비교

외부 이용자에게 같은 과업을 두 방식으로 수행하게 하되 순서를 교차합니다. 입력/대기/확인 시간을 모두 포함하고, 조건 누락과 수정 이유를 함께 기록합니다.
AI 초안을 고치는 시간이 직접 선택보다 길거나 잘못된 조건을 그대로 받아들이면 직접 선택 우선으로 바꾸는 근거입니다.
가상 시험으로 이 고객 효과를 대신 입증하지 않습니다.
