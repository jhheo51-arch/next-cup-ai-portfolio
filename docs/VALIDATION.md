# 검증 범위

## 현재 연결 시험

과일/요거트 특징을 포함한 AI 지시문과 추천 목록 5종으로 시험했습니다. 시험 입력을 먼저 evidence/connection-scenarios.json에 저장했습니다.
가상 입력이며 외부 참여자 0명입니다.

| 사례 | 실제 호출 | 결과 |
|---|---|---|
| R01 요거트/갈린 질감, 초콜릿 제외 | 최초 1회 | AI 조건 일치. 요거트 필수 확인 뒤 딸기 요거트 |
| R02 쌀 풍미 필수 | 최초 1회 | AI 조건 일치. 추천 보류 |
| R03 바닐라 입력 뒤 직접 수정 | 최초 1회 | AI 조건 일치. 검사기가 접힌 비선호 목록을 펼치지 않아 중단 |
| R03 절차 수정 재실행 | 추가 1회 | AI 조건 일치. 사용자 수정 뒤 딸기 요거트 |

최초 R03 오류는 AI 오류가 아니라 검사 절차 오류였습니다. 최초 기록은 삭제하지 않았습니다.
초기 3회 + 추가 1회 = 실제 API 호출 4회. 세 흐름을 확인했지만 전체 추천의 정확도나 성공률을 계산하기에는 사례가 적습니다.
사용자의 수정은 의도적으로 조건을 바꾼 시험이며 실제 AI의 오류를 수정한 사례는 아닙니다.
시간은 페이지 진입부터 AI 응답까지 2.233/2.287/1.614/재실행 9.063초입니다. 과거 서버 측정과 비교하지 않습니다.

## 추가한 진단

[설계 판단과 오류 분석](DECISIONS.md)에 어려운 표현 16개, 연결 중단, 질문 표시 수정, 운영 검토 분류 9개, 장애/복구 시험을 정리했습니다.

## 추가 비교와 연결 진단

기존 실제 응답 3개를 화면에서 재생해 직접 선택과 목표 조건을 맞췄습니다. 변경 값 수는 5/2/6개와 1/0/6개였으며 후보 결과는 같았습니다. 고객 시간과 편의는 측정하지 않았습니다. [원자료](../evidence/input-comparison.json).

평가 재시도는 기본 모델 2회, 대체 모델 2종 각각 2회가 연결 오류로 중단됐습니다. 별도 기본 모델 점검에서 HTTP 503/UNAVAILABLE를 확인했습니다. 일반 UPSTREAM 분류를 나누는 고정 503 검사는 수정 전 실패, 수정 후 통과했습니다. 실제 모델 품질 개선 결과가 아닙니다. [진단](../evidence/connection-diagnostic.json).

## 아직 확인하지 않은 것

실제로 음료를 고르기 쉬운지, 맛이 얼마나 비슷한지, 재구매로 이어지는지는 확인하지 못했습니다. 전체 메뉴 검색, 지점 재고, 장기간 운영도 시험하지 않았습니다.
