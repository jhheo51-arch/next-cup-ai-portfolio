# 검증 범위

## 현재 연결 시험

과일/요거트 특징을 포함한 AI 지시문과 추천 목록 5종으로 시험했습니다. 시험 입력을 먼저 evidence/connection-scenarios.json에 저장했습니다.
가상 입력이며 외부 참여자 0명입니다.

| 사례 | 실제 호출 | 결과 |
|---|---|---|
| R01 요거트/갈린 질감, 초콜릿 제외 | 최초 1회 | AI 조건 일치. 요거트 필수 확인 뒤 딸기 요거트 |
| R02 쌀 풍미 필수 | 최초 1회 | AI 조건 일치. 추천 보류 |
| R03 바닐라 입력 뒤 직접 수정 | 최초 1회 | AI 조건 일치. 검사기가 접힌 비선호 목록을 펼치지 않아 중단 |
| R03 절차 수정 재실행 | 추가 1회 | AI 조건 일치. 사용자 수정 뒤 딸기 요거트 |

최초 R03 오류는 AI 오류가 아니라 검사 절차 오류였습니다. 최초 기록은 삭제하지 않았습니다.
초기 3회 + 추가 1회 = 실제 API 호출 4회. 세 흐름을 확인했지만 전체 추천의 정확도나 성공률을 계산하기에는 사례가 적습니다.
사용자의 수정은 의도적으로 조건을 바꾼 시험이며 실제 AI의 오류를 수정한 사례는 아닙니다.
시간은 페이지 진입부터 AI 응답까지 2.233/2.287/1.614/재실행 9.063초입니다. 과거 서버 측정과 비교하지 않습니다.
