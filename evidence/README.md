# 검증 자료 안내

이 폴더에는 현재 제출본을 뒷받침하는 화면 캡처, 자동 검사 결과와 시험용 입력 자료가 있습니다. 실제 고객이나 실제 주문 데이터는 포함하지 않습니다.

| 먼저 볼 자료 | 용도 |
|---|---|
| [submission-check.json](submission-check.json) | 제출 자료와 현재 구조를 확인한 결과 |
| [submission-refresh-2026-10-08-v02.json](submission-refresh-2026-10-08-v02.json) | 현재 제출본을 다시 확인한 결과 |
| [taste-evaluation.json](taste-evaluation.json) | 취향 해석과 후보 비교를 위한 시험 자료 |
| [readme-preview.png](readme-preview.png) | README에 사용하는 시작 화면 |

`tests*.tap`, `diagnostic-tests.txt`는 자동 검사 출력이며, `release-*`, `recovery-*`, `connection-*` 파일은 오류와 복구 경로를 확인한 기록입니다. 이름에 날짜나 번호가 없는 기록도 당시의 검증 상태를 보존하기 위해 유지합니다.
