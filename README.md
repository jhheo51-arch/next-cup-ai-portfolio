# NEXT CUP

좋아했던 음료가 없어졌을 때 다른 메뉴를 비교하는 서비스입니다. AI가 입력한 기억에서 좋아하는 맛과 피할 맛을 정리하고, 사용자가 확인하면 등록된 음료 3종과 비교합니다.
스타벅스 AI 기획/개발 지원용 개인 프로젝트이며 공식 서비스가 아닙니다.

**기억 입력 → 취향 확인 → 대안 또는 추천 보류 → 남은 요구 기록**

## 어떤 음료를 고르는 데 도움이 되나요?

쌀이 필수가 아니라는 확인을 전제로, 갈린 얼음 질감이 좋고 커피 풍미를 피하면 **초콜릿 크림 칩 프라푸치노**가 비교 후보입니다. 바닐라 향을 원하고 커피가 괜찮다면 **바닐라 크림 콜드 브루**입니다. **쌀 풍미가 필수라면 세 후보 모두 추천하지 않습니다.**
맞는 조건과 빠진 조건을 함께 보여줍니다. 맛 재현, 무카페인, 실시간 판매를 보장하지 않습니다.

제가 좋아했던 이천 햅쌀 크림 프라푸치노에서 시작했습니다. 공개 자료를 조사하고 시험용 문장으로 추천 조건과 오류 처리를 확인했습니다. 외부 이용자에게 사용해 보도록 한 시험은 아직 하지 않았습니다.

## 실행

Node.js 24 이상, 추가 패키지 설치 없이 실행할 수 있습니다.

1. 이 저장소 폴더에서 `npm test`로 무료 자동 검사를 실행합니다.
2. `npm start` 후 `http://127.0.0.1:4322`에 접속합니다.
3. 키 없이 직접 취향을 선택할 수 있습니다. AI 사용 시 .env.example을 .env로 복사하고 본인의 Gemini 키를 설정합니다.

API 키는 서버에서만 읽고 Git에 포함하지 않습니다. 실제 호출은 계정 사용량이 발생합니다.
`node --env-file=.env tests/heldout-run.cjs`는 24회 유료 가능 호출을 수행하므로 기본 검사와 분리했습니다.
`node tests/decision-check.cjs`는 이전 커밋과 후보 비교를 다시 수행합니다.

## 범위

기본 추천 3종, 연구 비교 5종, 조사 사례 6개입니다. 전체 메뉴 API나 지점 재고 연동이 아닙니다.
AI는 문장 정리를 돕고, 사람의 확인 뒤 코드가 조건을 검사합니다. 기다리지 않고 직접 선택할 수 있습니다.
메뉴 요청/아이디어/초대형 커뮤니티는 **추천으로 해결하지 못한 요구를 수집하는 후속 기능**입니다. 실제 주문, 스타벅스 제출, 자동 제조 레시피, 매출/수요 예측은 아닙니다.
공식 출처 9건, 후기 3건은 고객 표본이 아닙니다. 정기 점검 완료 근거는 0회이며 예약을 실적으로 세지 않습니다.

저는 이천 햅쌀의 경험을 제공하고, 추천을 먼저 만든 뒤 메뉴 요청을 후속 기능으로 두도록 범위를 정했습니다. 조사 보조, 코드 작성과 자동 시험에는 Codex를 사용했습니다.
