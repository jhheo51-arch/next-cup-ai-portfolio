# NEXT CUP

**좋아했던 음료의 맛과 질감으로 다음 잔을 찾고, 조건에 맞는 후보가 없으면 추천을 보류합니다.**

[프로젝트 소개 PDF](submission/NEXT-CUP-Portfolio.pdf) | [시험 결과 Excel](submission/NEXT-CUP-Evidence.xlsx) | [화면 설명](docs/DEMO.md)

스타벅스 AI 기획/개발 지원용 개인 프로젝트이며, 스타벅스 공식 서비스는 아닙니다.

![NEXT CUP 시작 화면](evidence/readme-preview.png)

## 어떻게 고르나요?

`기억 입력 → 취향 확인 → 후보 비교 또는 추천 보류 → 남은 요구 기록`

- Gemini가 문장에서 취향을 정리하고, 사용자가 확인하거나 수정합니다. AI 없이 직접 선택할 수도 있습니다.
- 최종 후보는 코드가 필수 조건과 피할 특징을 검사해 고릅니다.
- 등록한 5종 중 쌀 풍미가 필수인 조건을 만족하는 후보는 없어 추천을 보류합니다. 남은 요구는 본인 브라우저에 저장합니다.

좋아했던 음료의 구수한 맛과 갈린 질감을 다시 찾고 싶었던 경험에서 시작했습니다. 같은 맛의 재현과 매장 재고 조회는 지원하지 않습니다.

## 어디까지 확인했나요?

| 구분 | 확인한 범위 |
|---|---|
| 자동 검사 | 코드 123개, 가상 AI 응답을 사용한 화면 검사 14개 통과 |
| 실제 AI 연결 | 5종 목록의 연결 시험 4회. 최초 실패와 재실행 기록 보존 |
| 남은 검증 | 어려운 표현의 해석 평가는 연결 오류로 미완료. 외부 이용자 효과 미측정 |

이전 3종 목록의 시험과 현재 5종 시험은 분리했습니다. AI 응답 재생 비교를 시간 절감이나 이용자 편의 개선으로 해석하지 않습니다. [전체 검증 기록](docs/VALIDATION.md)

## 직접 실행하기

Node.js 24 이상에서 저장소 폴더의 터미널에 입력합니다. 기본 실행은 별도 패키지 설치가 필요하지 않습니다.

```sh
npm start
```

http://127.0.0.1:4322 에서 ‘AI 없이 직접 선택할래요’를 사용할 수 있습니다. Gemini 연결은 [실행 안내](docs/HANDOFF.md)를 참고하세요.

<details>
<summary>코드와 화면 자동 검사</summary>

```sh
npm ci

npm run test:browser
```

화면 검사는 가상 AI 응답과 임시 저장소를 사용합니다. 실제 AI 요청은 보내지 않습니다. GitHub에서도 두 검사를 실행합니다.
