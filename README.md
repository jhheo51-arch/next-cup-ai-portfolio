# NEXT CUP

사라진 최애 메뉴의 취향을 다음 선택으로 연결하는 AI 서비스입니다.
스타벅스 AI 기획/개발 직무 지원을 위한 개인 프로젝트이며, 스타벅스의 공식 서비스가 아닙니다.

## 무엇을 만들었나

이천 햅쌀 크림 프라푸치노를 좋아했던 경험에서 시작했습니다.
기억하는 맛을 입력하면 Gemini가 선호와 비선호를 정리합니다. 사용자가 해석을 수정한 뒤, 코드가 등록 메뉴의 조건을 검사합니다.
비슷한 감각을 공유하는 후보는 차이점과 함께 보여주고, 필수 조건을 충족하지 못하면 추천하지 않습니다.
남은 요구는 재출시 요청이나 메뉴 아이디어로 기록할 수 있습니다.

본인의 실제 경험에서 문제를 정의하고, 공개 자료 조사와 가상 사용자 시나리오 시험으로 추천 조건 및 실패 대응을 검증했습니다. 외부 이용자 대상 사용성 검증은 후속 과제로 남겼습니다.

## 실행

Node.js 24 이상이 필요합니다. 외부 패키지 설치는 필요하지 않습니다.

1. 저장소를 내려받고 이 폴더에서 `npm test`를 실행합니다. 기본 시험은 Gemini를 호출하지 않습니다.
2. `npm start`로 서버를 실행합니다.
3. `http://127.0.0.1:4322`를 엽니다. 검증 화면은 `/#research`입니다.

키 없이도 수동 탐색을 사용할 수 있습니다. 실제 AI 기능을 사용하려면 .env.example을 .env로 복사하고 본인의 Gemini API 키를 입력합니다.
API 키는 외부 서비스 인증값이며 공개하면 안 됩니다. 서버에서만 읽고 Git에는 포함하지 않습니다.
모델 사용 가능 여부와 비용은 계정에 따라 다릅니다. 유료 호출 시험은 기본 테스트에 포함하지 않았습니다.

회원 기능은 별도의 시험 계정이 필요합니다. `node admin.cjs owner-setup`으로 초대 파일을 만든 뒤, 화면에서 본인의 새 비밀번호로 가입합니다.
GitHub 소스 공개와 서비스 인터넷 공개는 다릅니다. 이 서버는 자신의 컴퓨터에서만 접속됩니다.

## 구현과 한계

- Gemini 취향 추출, 사용자 수정, 조건 기반 추천
- 요청과 메뉴 아이디어, 초대형 커뮤니티, 투표와 근거 요약
- 실제/가상 비교 평가 분리, 공식 자료 검토 대기열, 보류와 버전 복구
- 기본 화면 후보 3개, 연구 비교 후보 5개, 조사 사례 6개

감각 태그는 설계자가 부여한 분류이며 실제 맛 유사도 측정값이 아닙니다.
전체 메뉴 API, 실시간 지점 재고, 주문, 제조 가능한 레시피 개발, 매출/수요 예측은 구현하지 않았습니다.
현재는 정해진 처리 순서의 AI 서비스입니다. AI가 자율적으로 주문하거나 게시하는 에이전트는 아닙니다.

## 증거를 읽는 기준

공식 출처 9개와 공개 후기 3개는 조사 자료입니다. 실제 이용자 표본이 아닙니다.
본인의 경험 응답 1건을 문제 정의에 사용했습니다. 외부 이용자 사용성 검증과 실제 비교 평가 완료는 0건입니다.
실제 Gemini 호출을 사용한 가상 문장 시험은 수정 후 6개 모두 통과했습니다. 이 수치를 고객 만족도나 모델의 일반 정확도로 해석하지 않습니다.
첫 결과와 수정 결과는 evidence 폴더에 함께 보존했습니다. 채점 기준도 수정했으므로 단순한 전후 향상률은 계산하지 않습니다.

작성자가 문제와 범위, 서비스 방향을 정했고 Codex가 조사 보조, 구현, 테스트 작성을 수행했습니다.
직접 코딩한 경력이나 실제 매출 성과로 설명하지 않습니다.
