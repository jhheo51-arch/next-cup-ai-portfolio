# NEXT CUP

좋아했던 음료의 기억을 확인 가능한 조건으로 바꾸고, 맞는 후보와 추천하지 않을 경우를 구분하는 AI 서비스입니다.
스타벅스 AI 기획/개발 지원용 개인 프로젝트이며 공식 서비스가 아닙니다.

**기억 입력 → 취향 확인 → 대안 또는 추천 보류 → 남은 요구 기록**

## 어떤 선택을 돕나요?

| 확인한 조건 | 결과 |
|---|---|
| 요거트 풍미 필수, 갈린 질감 선호, 초콜릿 제외, 쌀 필수 아님 | 딸기 딜라이트 요거트 블렌디드 |
| 갈린 질감 필수, 초콜릿 제외, 쌀 필수 아님 | 딸기 요거트와 망고 패션 프루트 |
| 쌀 풍미 필수 | 현재 5종 목록에서 추천 보류 |

맞는 특징과 다른 점을 함께 보여줍니다. 맛 재현, 건강 적합성, 실시간 판매는 보장하지 않습니다.
이천 햅쌀 크림 프라푸치노를 좋아했던 본인의 경험에서 시작했습니다. 이후 딸기 요거트 음료를 고른 이유는 맛의 유사성이 아니라 갈린 질감에 대한 선호와 당시 받은 추천이었습니다. 이 경험을 모든 고객에게 일반화하지 않습니다.

## 실행

Node.js 24 이상에서 아래 명령을 실행합니다. 서버는 본인 컴퓨터에서만 접속하도록 설정했습니다.

```bash
npm test
npm start
```

접속 주소: http://127.0.0.1:4322

Gemini를 사용하려면 .env.example을 .env로 복사해 본인 키를 넣습니다. 키가 없어도 'AI 없이 직접 선택할래요'로 비교할 수 있습니다. 키는 브라우저나 GitHub에 올리지 않습니다.
실제 AI 시험은 사용량이 발생하며 [HANDOFF.md](HANDOFF.md)의 별도 절차로 실행합니다.

## 코드 구조

- simple.html / simple.js: 현재 고객 흐름. 가입/투표/공개 게시 없음.
- portfolio.css / portfolio.js: 현재 화면 구성과 음료 일러스트.
- core.js: 5종 목록, 14개 특징, 필수/비선호 조건 검사.
- taste-policy.cjs / ai.cjs: Gemini 입력/출력 형식, 인용 검사, 제한 시간.
- server.cjs / research.cjs: 추천 API와 자료 확인일 검사.
- evidence/: 가상 입력, 실제 호출 결과, 자동 시험, 출처 확인본.
- index.html / app.js / connected.js / lab.js와 계정/연구 서버 모듈은 이전 구현입니다. 현재 고객 화면은 simple.html이며 이전 UI는 최신 시연 대상이 아닙니다.

## 범위와 역할

고객 기록은 브라우저 안에만 저장합니다. 서버로 수집하거나 다른 사람에게 공개하지 않습니다.
요청량을 매출이나 수요 예측으로 바꾸지 않습니다. 전사 전략, 매장 최적화, 자율 주문, 제조 가능한 레시피 생성은 구현 범위가 아닙니다.
공식 사이트 공개 자료는 출처와 확인일을 남겨 검토합니다. 공식 외부 API 연동이나 지점 재고 연결로 설명하지 않습니다.

본인은 문제와 서비스 범위를 결정하고 결과를 검토했습니다. 조사 보조, 코드 작성과 자동 시험에는 Codex를, 취향 문장 해석에는 Gemini를 사용했습니다.
